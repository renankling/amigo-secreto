🎁 Amigo Secreto

Um pequeno projeto em JavaScript, HTML e CSS para sortear amigos de forma divertida.
O usuário adiciona nomes em uma lista e, ao clicar em Sortear, o programa escolhe um nome aleatoriamente.

<hr>

📌 Funcionalidades

Adicionar nomes de amigos em uma lista.
Visualizar os nomes adicionados em tempo real.
Sortear aleatoriamente um amigo da lista.
Validação para evitar sorteio com menos de 2 pessoas.

<hr>

🚀 Tecnologias utilizadas

HTML5
CSS3
JavaScript (ES6)
